个人作品集网站（Portfolio Website）开发规范与版本迭代方案
一、开发定位
独立开发个人技术作品集网站，替代传统简历展示形式，用于求职技术背书。网站集中展示个人技术栈、项目经历、RAG+Agent智能问答系统Demo、代码仓库、技术笔记与个人履历，打造标准化、专业化的技术个人门户。可参考https://lvyovo-wiki.tech/
整体遵循大厂前端工程化开发标准，严格执行版本迭代、文档留档、测试校验、Git版本回溯、全链路回归测试规范。
二、开发角色与协作规则
1. 开发角色：资深前端/全栈开发工程师，独立完成网站架构、开发、美化、部署、归档、测试全流程
2. 你作为主管/协作同事，负责需求确认、版本验收、权限与环境审批
3. 所有迭代版本严格区分大版本、小版本，每一次迭代必须输出对应版本文档、更新日志、测试记录
4. 所有代码、静态资源、配置文件、文档全部关联个人GitHub仓库（git@github.com:YXY614-ASH/personal-site.git），每一个版本迭代必须提交、打Tag、归档留痕，支持永久回溯
5. 后续可补充新增需求、新增页面、新增模块，规则同步实时更新
三、通用开发 & 发布强制规则（同步上位机项目规范）
1. 版本留档规则：所有大版本、小版本迭代必须独立写版本日志、功能清单、优化点、已知问题、测试报告，严禁无文档迭代
2. Git管理规则：所有代码更新、页面新增、样式优化、配置修改全部提交至GitHub仓库，每个正式版本打Release/Tag，全程可回溯、可复盘
3. 验收测试规则：每完成局部开发，必须执行全量校验：页面兼容性、UI一致性、链接有效性、响应式适配、跳转逻辑、资源加载、部署稳定性、回归测试，确认无新增Bug、无样式错乱、无失效链接、无部署异常方可交付
4. 环境申请规则：开发、构建、部署所需框架、工具、运行环境、部署平台、依赖包缺失时，提前说明：名称、版本、可信来源、用途、风险、替代方案，获得授权后方可安装配置，所有环境变更写入版本文档
5. 安全规范：禁止硬编码密钥、隐私信息、敏感配置，所有隐私配置使用环境变量，网站公开内容无隐私泄露风险
四、项目核心实现目标
1. 搭建标准化个人技术作品集官网，替代简易简历，作为求职核心背书
2. 完整展示个人简介、技能栈、教育经历、项目经历、技术笔记
3. 重点展示 RAG+Agent 本地知识库AI问答项目（Gradio），含项目介绍、架构说明、运行截图、GitHub源码链接、在线Demo跳转
4. 实现页面自适应、高颜值UI、流畅交互、稳定部署
5. 支持简历下载、仓库跳转、项目预览、技术博客展示
6. 全程工程化规范开发，版本迭代可追溯，文档完整可验收
五、分版本迭代发版规划（V1~V5 完整迭代）
V1.0 基础架构与骨架版本（初始版本）
核心目标：完成网站整体架构搭建，初始化项目工程，搭建基础页面骨架与部署流程
实现功能：
- 完成项目工程初始化，采用标准化前端工程化结构
- 搭建网站基础路由、全局样式、统一布局、导航栏、页脚
- 搭建基础页面框架：首页、关于我、项目作品集、技术笔记、简历下载页面骨架
- 配置 GitHub 自动部署/ Vercel 持续部署流程
- 完成基础环境适配、依赖配置、项目规范化配置
验收标准：项目可正常运行、无报错、部署流程通畅、页面骨架完整、工程结构规范，完成V1.0版本文档与Git版本归档
V2.0 基础内容填充与UI标准化版本
核心目标：完成全站基础内容填充，统一UI风格，实现基础页面完整展示能力
实现功能：
- 首页内容完善：个人简介、技术标签、岗位方向、核心能力展示
- 关于我页面：教育背景、技能栈、技术方向、个人优势完整填充
- 简历模块：上传可下载PDF简历，实现在线预览/下载功能
- 全站UI风格统一、配色规范、排版标准化
- 适配电脑端、手机端基础响应式布局
验收标准：所有基础页面内容完整、UI整洁统一、响应式无错乱、链接正常、可正常部署访问，输出V2.0版本更新文档并归档Git
V3.0 核心项目作品集专项完善版本（重点版本）
核心目标：重点落地AI知识库RAG+Agent项目展示，打造网站核心求职亮点
实现功能：
- 新增智能知识库问答系统（RAG+Agent+Gradio）专属项目详情页
- 页面录入：项目介绍、技术栈、迭代过程、核心亮点、解决问题、工程思路
- 嵌入项目运行截图、功能演示说明、架构逻辑说明
- 配置 GitHub 源码跳转链接、在线Demo跳转入口
- 支持项目亮点高亮展示，突出可插拔LLM、RAG检索优化、Agent智能体、本地私有化部署、Gradio可视化搭建核心能力
- 补充其他校园/技术项目基础展示模块
验收标准：核心项目展示完整、逻辑清晰、链接有效、图文匹配，无内容错误，适配多端展示，完成V3.0版本文档与版本归档
V4.0 功能完善与交互优化版本
核心目标：优化全站交互体验、动画效果、加载速度，完善网站细节能力
实现功能：
- 添加页面过渡动画、hover交互、滚动动效，提升网站质感
- 优化图片加载、资源压缩、页面加载速度
- 完善404页面、路由容错、异常兜底展示
- 优化移动端适配细节，修复兼容性问题
- 完善技术笔记模块框架，支持后续持续更新
验收标准：全站交互流畅、无卡顿、无兼容Bug、容错完善、加载速度优化到位，整体观感专业化，输出V4.0优化文档
V5.0 全量测试、回归优化、最终正式版本
核心目标：全链路回归测试、Bug修复、细节精修，完成网站正式上线交付
实现功能：
- 全站全量回归测试：UI、链接、跳转、下载、适配、部署、资源加载
- 修复所有细微Bug、样式偏差、适配问题
- 统一全站文案、格式、排版，标准化输出
- 完善GitHub仓库README、网站介绍、项目说明
- 完成正式版部署固化，锁定V5.0正式Release版本
验收标准：零功能性Bug、零失效链接、页面完美适配、部署稳定、文档齐全、版本可永久回溯，作为求职正式作品集官网对外交付
