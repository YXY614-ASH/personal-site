## 工程选择与优化

使用已有 Node.js 原生能力实现构建，生产环境不依赖第三方包安装。主要内容在构建阶段写入独立 HTML，JavaScript 只增强交互。

图片压缩为本地 WebP，仅首页背景优先加载，项目图延迟加载。图标从现有 Lucide 包中提取实际使用部分，避免携带完整图标库。没有远程字体、追踪脚本、运行时 CDN 或外部 API 调用。

路径使用相对链接，适配 GitHub Pages 仓库子目录；404 通过部署基础路径处理任意深层地址。

## 已知限制

1. 教育、完整履历、正式 PDF 简历尚未提供；页面保留真实待补充状态。
2. AI 知识库项目的实际仓库、Demo、截图与实现资料尚未提供；当前仅为展示框架。
3. 指定仓库 SSH 可访问，匿名 GitHub API 返回 404。未将受限源码链接作为公开可用入口。
4. 用户选择先本地验收，本次不进行公网发布。后续上线需要 GitHub Pages 开通并设置 `PAGES_ENABLED`，或连接 Vercel 账号。
5. 真实浏览器验收基于本机 Edge / Chromium；尚无 Safari、Firefox 运行环境，不宣称已实测这些引擎。
