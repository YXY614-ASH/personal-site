- 日期：2026-09-09
- 范围：将现有 chatbot V0.5 课程助手接入个人作品集的“本地知识库智能问答”项目页，并提供本机 Demo 启动入口。

## 真实能力接入

- PDF 资料问答：`pypdf` 提取页面文本，轻量检索相关片段并保留来源页码。
- 题目解析卡：固定提示模板输出题型、条件、思路、公式、答案和易错点。
- 学习计划卡：固定模板输出目标、阶段安排、每周行动与练习项目。
- 课程助手 Agent：按问题自动选择 PDF 检索或计算器，再将工具结果交给模型组织回答。
- 安全计算器：使用 AST 白名单，只支持数字、括号和基础运算，不执行任意代码。
- 多轮流式对话：Gradio ChatInterface + DeepSeek OpenAI 兼容接口。

作品集项目页不复制 chatbot 源码，而是读取已核实的能力和版本信息，链接到原始仓库与本机 Demo。仓库当前需要授权访问，页面没有把它标为公开源码。

## 本机 Demo

运行 PowerShell：

```powershell
$env:CHATBOT_PATH = 'C:\Users\Asus\Desktop\新建文件夹 (4)\chatbot'
# 可选：只有配置新密钥时才连接 DeepSeek，绝不要使用旧 config.py 中暴露的密钥
$env:DEEPSEEK_API_KEY = '在本机安全设置的新密钥'
npm run demo:chatbot
```

访问 `http://127.0.0.1:7861/`。启动器禁用旧的公开凭据；未设置 `DEEPSEEK_API_KEY` 时，PDF 检索与计算器仍可运行，模型回答显示未连接状态。启动器不提供 `--share`，不会自动生成公网链接。

## 安全与环境记录

旧 chatbot `config.py` 中存在已经暴露的 API key，接入没有读取或复用它。启动器在导入客户端前以环境变量覆盖配置；文档只描述变量名，不记录密钥值。没有安装依赖，复用用户 Python 环境已有 Python 3.12.10、OpenAI SDK 3.3.1、Gradio 6.26.0 和 pypdf 6.16.2。

## 验收与限制

新增接入测试覆盖：旧密钥未使用、真实本地计算器、真实 PDF 页码检索、Agent 组合工具规划、无密钥模型提示以及 chatbot 原有至少 15 项回归测试。完整结果见 `V0.3-test-report.md`。

模型回答需要用户自行在本机配置新密钥；当前网站只展示本机入口，不声称有在线 Demo。chatbot 仓库的工作区 `output/` 保持原样，不复制到个人网站。
