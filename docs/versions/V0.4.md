# V0.4 版本开发文档

- 日期：2026-09-09。
- 对应新开发规则第四阶段：功能完善与交互优化；延续用户要求的 V0.x 命名。
- 范围：站点交互、笔记持续更新能力、响应式素材、路由和资源异常处理。
- 本地验收，保留 GitHub Pages / Vercel 配置与所有历史标签。

## 功能清单

1. 将笔记元数据与分节正文集中到 `src/data/notes.mjs`，自动派生文章路径、目录、列表日期、分类与相关阅读。
2. 新增基于 chatbot V0.5 的工具边界笔记，保留原 V0.1 开发笔记正文。首页六项项目拆解继续保留。
3. 笔记支持分类、多词搜索、清空、日期排序；通过 q / category / sort 查询参数保存状态，刷新和返回时恢复。
4. 文章目录提供锚点、当前章节与阅读进度；正文使用纯文本转义，关闭脚本后仍能浏览。
5. 页面切换采用 CSS 入场动画；滚动反馈采用 IntersectionObserver 与 Web Animations，内容默认可见。减少动态效果时禁用动效。无脚本时不启用动画。
6. 移动导航增加焦点管理、展开/关闭图标与短屏滚动，无脚本时使用备用导航。主要手机工具按钮至少 44px。
7. 根据视口选择手机裁切图、1280px 或原始 WebP，保留宽高与高优先级首图；预览失败时保持项目入口可用。
8. 本地 HTTP 支持 gzip、ETag、304、HEAD；目录重定向保留搜索条件，404 基址适配仓库子目录，缺失构建返回可重试的 503。

## 环境与验证

生产构建继续使用 Node.js 原生模块，无新增依赖。开发素材与浏览器验收复用已有 Sharp、Lucide、Playwright 和 Microsoft Edge；未安装新软件。chatbot 源项目保持原样，沿用 V0.3 的启动器与环境变量。

验证命令、实际结果与性能数据见 [测试报告](V0.4-test-report.md)。浏览器回归默认只写 artifacts，不再每次修改已跟踪的预览素材，显式 UPDATE_PREVIEW=1 时才刷新。

## 限制

真实 PDF 简历尚未提供；模型回答需要本机配置新 DEEPSEEK_API_KEY。本机 PDF 检索不是向量数据库或 OCR，内容没有声称实现这些能力。无公网发布、无密钥联网生成验收，gzip/ETag 的实测仅适用于本地服务。浏览器缺少滚动动画 API 时直接显示内容。
