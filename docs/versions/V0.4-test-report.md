## 静态与 HTTP

`npm run check`：12 项通过。覆盖版本一致性、十页构建、内部资源链接、笔记目录、内容转义、响应式素材预算、子目录路由、查询参数重定向、gzip 协商、ETag / 304 / HEAD，以及构建缺失的 503 恢复。

## 浏览器与回归

使用现有 Microsoft Edge 152.0.4191.66 / Chromium 与 Playwright。

- 50 组页面 / 视口检查通过：10 页 × 1440、1920、768、390、320px，含资源加载、标题与按钮溢出、资料一致性、首屏边界及手机图片选择。
- 12 组交互检查通过：移动导航、项目筛选、笔记搜索与空状态、查询参数恢复与排序、文章目录与进度、简历缺失状态、404 恢复、版本记录、短屏菜单、无脚本手机访问、减少动态效果、图片故障兜底。
- 普通访问零脚本错误、零失败资源；图片兜底测试主动返回一次 503，属于预期故障注入。
- 已目视检查桌面与手机的笔记列表、文章目录和正文截图，未见内容遮挡与横向溢出。
- `python -B tests/chatbot_integration.py`：6 项接入测试通过，其中包括原 chatbot 至少 15 项回归测试。
- 截图与机器报告保存在 `artifacts/`，不提交运行产物。

复现：先运行 `npm run check`，完成后设置已有 `TOOL_NODE_MODULES` 和 `BROWSER_EXECUTABLE` 运行 `npm run test:browser`。避免两个会重建 dist 的命令并行执行。chatbot 测试需要设置原项目 `CHATBOT_PATH`。
