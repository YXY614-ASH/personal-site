## 内容与优化

当前日期早于毕业年份，采用“预计”表述，不暗示已经取得毕业证或学位。院校及毕业时间由共享教育组件展示，主学方向集中维护在 `site.studyAreas`，三个页面复用相同数据。

首页与关于我突出本次确认的学习方向。AI 和 Web 作为延伸探索保留，项目结构不变。未编造入学时间、成绩、实习、STM32 等具体硬件经验或熟练程度。

修正原本截断第三段版本号的显示方式，使修订版本 V0.2.1 可在页面完整呈现。V0.1 和 V0.2 文档、截图与标签保持为历史记录。

## 环境与限制

复用已有 Node.js、Git、Playwright、Sharp 和 Edge，没有新增安装、账号配置或付费服务。按用户已选择的本地验收方式交付，不触发公网发布。

正式 PDF 简历及 AI 项目的实际素材、Demo 和源码地址仍待提供，缺失状态继续保留。浏览器验收为 Edge / Chromium，不宣称已测试 Safari、Firefox 或实体手机。
