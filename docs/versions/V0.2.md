## 优化说明

学历和专业统一维护在 `src/data/site.mjs`，关于我和简历页通过共享组件呈现，避免多处资料不一致。当前版本标签由内容数据中的版本号生成，并校验其与 package 版本一致。

CI 构建产物由固定的首版名称改为包含提交号，便于识别不同迭代。公网发布仍需要显式启用和手动触发。

V0.1 的开发笔记、文档、截图和标签均作为历史保留。原有页面导航、项目筛选、笔记搜索、404 恢复和简历缺失状态继续纳入回归。

## 环境变更

没有安装依赖或更改工具环境。继续使用现有 Node.js、Git、Playwright、Sharp 和 Microsoft Edge；站点生产构建无需第三方依赖。实际工具版本见本版本测试报告。

## 已知限制

1. 未提供院校和就读时间，不推断毕业年份、学位、成绩或学习经历。
2. 正式 PDF 简历未提供，下载继续保持禁用，资料预览不冒充正式简历。
3. AI 项目真实截图、Demo 和源码地址仍待提供。
4. 本版为已确认资料的增量完善，不宣称新版规则中后续阶段的所有内容已完成。
5. 公网发布以及未安装的 Safari / Firefox 浏览器未做实际验证。

执行 `npm run check` 与 `npm run test:browser`，结果记录于 `V0.2-test-report.md` 和 `V0.2-browser-results.json`。功能、配置与文档提交到指定仓库，注释标签为 `V0.2`。版本提交以 `git rev-parse V0.2^{commit}` 为准。
