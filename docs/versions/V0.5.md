# V0.5 版本开发文档

- 日期：2026-09-09。
- 对应新开发规则第五阶段：全量测试、回归优化、最终正式版本；站点实际版本沿用 V0.x 命名。
- 范围：最终内容和版本统一、发布前安全审计、静态发现文件、托管响应头与全链路回归。
- 用户选择先本地验收，继续保留 GitHub Pages / Vercel 配置，不自动发布公网。

## 正式版清单

1. 版本号统一为 `0.5.0`：package、站点数据、页脚、构建信息、项目状态和版本记录一致。
2. 项目详情页补齐 V0.5 正式发布记录，保留 chatbot V0.5 作为独立项目版本说明。
3. `npm run audit` 检查生成页面的标题、author、canonical、manifest、外链 `noopener` 属性，检查静态发现文件和源码中的常见凭据模式。
4. 所有页面提供 manifest、author、Open Graph、Twitter card 和相对 canonical，增加 `robots.txt`，兼容根路径及 GitHub Pages 子目录。
5. 本地服务和 Vercel 配置统一 CSP、Permissions-Policy、Referrer-Policy 与 MIME 类型；本地继续支持 gzip、ETag、304、HEAD 和缺失构建 503。
6. 公开仓库入口、chatbot 本机 Demo、笔记搜索和文章目录继续可用；正式简历 PDF 尚未提供时下载按钮保持禁用。

## 验收边界

`npm run check` 运行构建、发布审计和 13 项静态/HTTP 测试。浏览器回归覆盖十个页面、五组视口和 13 组交互；设置 `CHECK_GITHUB_LINKS=1` 时额外在无登录会话中验证个人主页、personal-site 和 chatbot 的真实 HTTP 200 跳转。chatbot 接入测试覆盖 6 项，并运行原项目至少 15 项回归。

## 已知限制

正式 PDF 简历尚未提供，因此没有伪造下载地址。模型生成需要本机配置新的 `DEEPSEEK_API_KEY`，本次不进行联网生成验收。浏览器验证使用现有 Microsoft Edge / Chromium，不代表 Safari、Firefox、实体手机或公网部署已验证。CSP、gzip 与 ETag 的实际服务检查针对本地 Node 服务，GitHub Pages 和 Vercel 的最终传输由平台负责。
